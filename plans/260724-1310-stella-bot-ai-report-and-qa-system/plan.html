Tổng quan

Bot Stella vừa qua đợt nâng cấp lớn (service-flow, retention, cross-post) và đã chuyển DB sang Supabase. Plan này thêm một lớp AI gồm ba năng lực trên cùng một client dùng chung:

  • Hạ tầng AI — một client OpenAI-compatible (agentgw.cloud), key ở .env, model+endpoint ở config, không bao giờ log/commit.
  • Kho wiki — bảng WikiEntry seed sẵn plugin phổ biến; admin thêm qua /add wiki.
  • Trợ lý Q&A — kênh riêng, reply-to-bot để tiếp tục hội thoại; /ask mọi nơi; cooldown + trần đồng thời.
  • Báo cáo AI hàng ngày — 21-22h VN, đọc 24h chat (live, không lưu), tóm tắt + changelog Mojang, đăng forum; thay thế digest cũ.
Mỗi lần gọi AI là tốn token. Cooldown + khóa mỗi-người-một-câu + trần đồng thời là các van chi phí. Đọc chat cộng đồng: tóm tắt rồi bỏ, không bao giờ lưu nguyên văn.

Luồng phụ thuộc

P1 Prereq → P2 AI Client → P3 Wiki Store → P4 Q&A · P5 Daily Report

Phase 2 là nền — mọi thứ gọi nó. Phase 3 trước Phase 4 (Q&A cần fetch wiki). Phase 5 chỉ phụ thuộc Phase 2, độc lập với Q&A, và gỡ bỏ scheduler digest cũ.

Các Phase — bấm để xem chi tiết

Tiêu chí thành công (toàn plan)

  • AI client gọi agentgw theo chuẩn OpenAI; key chỉ ở .env, không log.
  • /add wiki (admin) lưu link wiki; seed có mặt ở lần chạy đầu.
  • Trong kênh Q&A, reply tin bot ping bạn thì tiếp tục; reply tin bot trả người khác thì bỏ qua.
  • /ask chạy mọi nơi; cooldown + khóa một-câu-mỗi-người + trần đồng thời được thực thi.
  • Báo cáo tối đăng forum: tóm tắt chat + bài nổi bật + changelog Mojang (bỏ qua nếu fetch lỗi).
  • Scheduler digest cũ đã gỡ; không đăng trùng.
  • npm run build sạch.

Chi phí & An toàn

  • Token/quota: cooldown + single-in-flight + trần đồng thời là van chặn; báo cáo 1 lần/ngày (bị chặn trên).
  • Riêng tư: đọc chat cộng đồng — fetch live, tóm tắt, không lưu nguyên văn; báo cáo là tổng hợp, không trích DM/kênh riêng.
  • Secret: API key chỉ ở .env, redact khỏi mọi log (dùng lại pattern redact của Facebook manager).
  • SSRF: chỉ fetch URL wiki do admin thêm, http(s), timeout + giới hạn kích thước, không follow redirect nội bộ.
  • Prompt injection: nội dung wiki/chat là dữ liệu không tin cậy, phân định rõ trong prompt; Q&A chỉ trả text, không thực thi hành động.

Nguồn tham chiếu

  • Mojang Java patch notes (ổn định hơn scrape HTML): https://launchercontent.mojang.com/v2/javaPatchNotes.json
  • Minecraft articles (Mojang chính thức): https://www.minecraft.net/en-us/articles
  • agentgw endpoint (cần xác nhận + rotate key): https://agentgw.cloud

Câu hỏi mở

  • Base URL + model id chính xác của agentgw — user xác nhận/rotate key trước go-live (key hiện là test key, sẽ thay).
  • Ngân sách token mỗi báo cáo — 24h chat qua 6 kênh có thể lớn; Phase 5 phải cap/truncate input.
